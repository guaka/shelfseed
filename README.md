# ShelfSeed

ShelfSeed prepares openly licensed book collections for distribution by torrent.
The first [children's book pack](drafts/children/cc-by-4.0/README.md) is a four-edition draft, not the planned 2,000-edition release.

## Release model

See [RELEASES.md](RELEASES.md) for immutable packs, catalog revisions, rights review, and unscheduled updates.

## Roadmap

- Grow the reviewed children's catalog toward 2,000 distinct language editions, including educational books and comics. Prioritize Portuguese from Portugal, Dutch, and readers aged 10–15 in upcoming packs.
- Maintain separate packs for CC BY, CC BY-SA, and public-domain works. Public-domain packs must name the jurisdiction whose status was checked.
- Later, consider moving and renaming Libcat into ShelfSeed. This is a planning item only; no Libcat code or deployment changes are part of this draft.
